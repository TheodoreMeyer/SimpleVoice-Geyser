# 0.1.5 Release
 _Bringing velocity support and higher security_

## Velocity
- Full velocity support is now available! 
- The proxy plugin can be installed on a velocity proxy to allow players to seamlessly move between backend servers without needing to re-authenticate.
- The proxy supports certificates, meaning we can now use Https!

## Security
- Microphone now sends opus codec to the server, which is more secure than sending raw PCM audio.
