# 0.1.5 Release

_Velocity support, Opus microphone audio and 26.3 support._

## Velocity

- A new proxy plugin, `Svg-Velocity`, serves the voice page from your Velocity proxy. Players sign in once and keep their voice connection while they move between backend servers.
- The proxy can serve HTTPS itself (beta), or sit behind a reverse proxy.
- Passwords are set on the proxy with `/svg pswd`. Bedrock players get a form through Geyser on the proxy.
- Setup guide: [Velocity Proxy Setup]({% project_link velocity %}).

## Audio

- The microphone is now sent to the server as Opus, which uses far less bandwidth than raw PCM. Older clients that only send PCM still work unless you set `server.audio.mic.allowLegacy` to `false`. See [Audio Transport]({% project_link install/audio-transport %}).
- Some audio settings changed to reduce audio problems on remote connections.

## Svg-App

Svg-App 1.1.0 supports 0.1.5 servers and Velocity server switching. See [Svg-App]({% project_link app %}).

## Compatibility

- Full Minecraft 26.3 support.
- The web page is also available in Spanish.

## Fixes

- Fixed a logging problem on Fabric.
- Fixed the join message not being read from the config.

## Upgrading

No password reset is needed. New config options are added automatically. See [Upgrading]({% project_link install/upgrading %}).
